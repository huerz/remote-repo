## 单条结构

```json
{
  "title": "静夜思",
  "author": "李白",
  "dynasty": "唐",
  "genre": "诗",
  "content": "床前明月光，疑是地上霜。\n举头望明月，低头思故乡。",
  "translation": "明亮的月光洒在床前……",
  "note": "①床：井栏，一说坐卧的器具。②疑：好像。",
  "appreciate": "全诗二十字……",
  "tag": "思乡",
  "cover": "jys.jpg"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | String(128) | 必填 |
| `author` | String(64) | 必填 |
| `dynasty` | String(16) | 必填，唐 / 宋 / 元 / 清 |
| `genre` | String(16) | 诗 / 词 / 曲 |
| `content` | Text | 必填，原文，句间用 `\n` 换行 |
| `translation` | Text | 白话译文 |
| `note` | Text | 注释，用 ①②③ 编号 |
| `appreciate` | Text | 赏析 |
| `tag` | String(64) | 豪放 / 婉约 / 山水 / 爱国 / 田园 / 边塞 / 咏史 / 思乡 / 送别 / 咏物 … |
| `cover` | String(200) | 封面图文件名，对应 `images/books/<分类>/`，没有就填 null |

## 导入

```bash
cd cls_svr
.venv\Scripts\python.exe scripts\seed_poems.py --dry-run   # 只校验 JSON
.venv\Scripts\python.exe scripts\seed_poems.py             # 补齐新增
.venv\Scripts\python.exe scripts\seed_poems.py --reset     # 清表后全量重灌
```

去重键：标题 + 作者 + 朝代，重复执行不会产生脏数据。
